# LexyRead example

LexyRead is the first real project used to exercise UI Iceberg.

One earlier episode found a navigation false convergence: the canonical learner navigation and an existing regression rule described a five-label mobile navigation contract, while a later legacy CSS owner could reintroduce an obsolete icon-only regime. That class is represented in the benchmark as `UI-001`.

The next human-journey benchmark is intentionally narrower:

> A learner encounters an unfamiliar complex expression, opens an explanation, and continues reading without losing passage context.

UI Iceberg should distinguish technical evidence (the explanation control exists and can be activated) from the stronger human claim (the learner can discover the action and resume the task). The latter remains unproven until licensed human/task evidence exists.
