# UI Iceberg PackSpec v0.7.2

This directory anchors the open-source product to the v0.7.2 specification line.

The product surface intentionally uses familiar funnel vocabulary while the compiler maps it into the PackSpec's deeper structures: G1-G12, UI-12, UX-12, QP01-QP16, ContextOfUse, TaskGraph, matrices, semantic entropy/MissSet, probes, witnesses/antiwitnesses, First Bite, admission, repair/replay, TERM, and the mature-testing primitive layer.

The full normative PackSpec is maintained as `ui-iceberg-packspec-v0.7.2.yaml` in this directory.
