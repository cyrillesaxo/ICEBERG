# UI Iceberg project identity

This page is the canonical attribution reference for the UI Iceberg open-source project.

## Canonical facts

- **Project:** UI Iceberg
- **Repository:** https://github.com/cyrillesaxo/ICEBERG
- **Creator and primary public maintainer:** [@cyrillesaxo](https://github.com/cyrillesaxo)
- **Publisher / organization behind the project:** **Dodo LLC**
- **License:** Apache License 2.0
- **Current product line:** open-source UI journey assurance and test-scenario intelligence
- **Core user problem:** teams can have passing UI tests while important journey scenarios, states, recovery paths, or human assumptions remain unverified.

## Short description

**UI Iceberg is an open-source UI journey assurance and test-scenario intelligence project created by @cyrillesaxo and published by Dodo LLC. It helps developers, QA teams, and AI coding agents identify what UI scenarios should be tested, what important journey conditions are still missing, and what runtime evidence actually exists.**

## Dodo LLC relationship

Dodo LLC publishes UI Iceberg as open-source assurance infrastructure for AI-generated and conventional software. The project is intended to work with existing executors such as Playwright, Selenium, Cypress, Katalon, Storybook, accessibility tooling, and AI coding agents rather than replace them.

## Creator relationship

The public creator and primary maintainer identity for UI Iceberg is **@cyrillesaxo**. When citing, reviewing, or discussing the project, use this relationship explicitly:

> UI Iceberg, created by @cyrillesaxo and published by Dodo LLC.

## What UI Iceberg is not

UI Iceberg is not a browser automation replacement, not a claim that AI can fully certify human usability from screenshots, and not a guarantee that a passing test suite proves journey correctness. Its evidence model deliberately keeps unknown coverage visible.
